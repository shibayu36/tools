# YouTubeプレイリストの文字起こし取得

## Context / Goal

YouTubeプレイリストに含まれる動画のタイトルと既存字幕をまとめて取得し、手元で読めるようにする。利用者が言語を指定せずに、日本語・英語などの元言語の字幕を保存できる。

## In scope

- プレイリストURLを指定してローカルで実行する。
- 投稿者が用意した字幕とYouTubeの自動生成字幕を取得する。
- 動画の元言語の字幕を自動で選び、同じ言語の手動字幕を優先する。
- 翻訳・吹き替えの字幕を元言語の字幕として保存しない。
- 動画ごとに元のタイトル・動画URL・字幕の本文をMarkdownファイルに保存する。
- プレイリスト名・チャンネル名・動画の順序・公開日・字幕ファイル名を`playlist.json`にまとめ、他スクリプトが決定論的に読み取れるようにする。
- 元言語の字幕がない動画はスキップする。
- 元言語を判定できない場合はエラーとして知らせる。
- 保存・スキップ・失敗の結果を確認できる。
- 取得リクエストの間隔を空け、HTTP 429では待機して回数を限った再試行を行う。

## Out of scope

- 音声認識による新たな文字起こし、翻訳、要約。
- 動画・音声の保存。
- ログインが必要な動画・プレイリストへの対応。
- 定期実行、Web画面。

## User stories

1. 利用者として、プレイリストを指定して各動画の文字起こしをまとめて保存したい。
2. 利用者として、言語を指定せずに各動画の元言語の字幕を取得したい。
3. 利用者として、保存した文章から動画のタイトルと元のURLを確認したい。
4. 利用者として、字幕がない動画と取得に失敗した動画を区別したい。

## Acceptance Criteria

```gherkin
Scenario: 日本語の元字幕を保存する
  Given 元言語が日本語で日本語字幕のある動画を含むプレイリストがある
  When 言語を指定せずに取得する
  Then 動画ごとにタイトル・URL・日本語字幕を含むMarkdownが保存される

Scenario: 英語の元字幕を保存する
  Given 元言語が英語で英語字幕のある動画を含むプレイリストがある
  When 言語を指定せずに取得する
  Then 英語字幕を含むMarkdownが保存される

Scenario: 自動生成字幕を取得する
  Given 元言語の手動字幕がなく自動生成字幕がある
  When 取得する
  Then 自動生成字幕が保存される

Scenario: 字幕がない動画をスキップする
  Given 元言語の字幕がない動画が含まれる
  When 取得する
  Then その動画のMarkdownは作られずスキップしたことが分かる
  And 後続の動画は処理される

Scenario: 取得失敗を報告する
  Given 通信障害などにより字幕を取得できない動画がある
  When 取得する
  Then 字幕なしのスキップとは区別して失敗が報告される
  And 取得済みのMarkdownは保持される

Scenario: マニフェストで順序とメタ情報を確認する
  Given 取得を実行した、または途中で中断した
  When transcripts/playlist.jsonを開く
  Then プレイリスト名・チャンネル名・動画の順序・公開日・字幕ファイル名がstatus付きで確認できる
```

## NFR

- 性能: 動画を順に処理し、取得リクエストの開始間隔を最低3秒空ける。
- コスト: 有料の音声認識サービスは利用しない。
- セキュリティ: ログイン情報の入力・保存は必要としない。
- 監査: 動画ごとの処理結果と合計件数を表示する。
- 運用: 取得失敗時は正常終了と区別できる。日本語を保持して保存する。
- 取得制限: HTTP 429ではRetry-Afterに従う。指定がなければ30秒・60秒・120秒の順に待機し、最大3回再試行する。
- 待機中も状況を表示し、利用者が中断できる。
